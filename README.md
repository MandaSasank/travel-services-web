# Online Travel Service Website

A responsive travel service website built using HTML, CSS, and JavaScript. The project helps users explore destinations, compare travel packages, review transport options, view a gallery, submit enquiries, and send booking requests with an estimated trip cost.

**Live Demo:** https://mandasasank.github.io/travel-services-web/

## Features

- Responsive multi-page website with shared navigation
- Mobile hamburger navigation menu
- Theme selector with Normal, Dark, Ocean, and Sunset modes
- Destination search and category filtering
- Travel package budget filtering
- Package category filtering and price sorting
- Package details modal with inclusions
- Favourite destination/package buttons saved with browser localStorage
- My Favourites section on the homepage
- Searchable package and transport tables
- Booking form with email, phone, and travel date validation
- Booking summary confirmation before final submission
- Live booking cost estimator based on destination, travel mode, travelers, and number of days
- Trip planner checklist saved with browser localStorage
- Gallery lightbox using JavaScript
- Contact/enquiry form with mailto email draft for venkatasasank69@gmail.com
- Toast notifications for user actions
- Testimonials and booking steps sections

## Technologies Used

- HTML5
- CSS3
- JavaScript
